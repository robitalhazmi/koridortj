End-to-End Enterprise Transit Data Architecture

Medallion Design

1. Ingestion Layer

  • GTFS Puller: Weekly Python pipeline downloading official TransJakarta transit feeds.
  • Kafka KRaft: Real-time replay producer streaming transaction payloads to taps.raw.
  • Dead-Letter Queue: Pydantic schema validation isolating malformed messages to taps.deadletter.

2. Storage & Modeling

  • PostgreSQL 16: High performance relational storage (schemas: raw, staging, warehouse).
  • dbt Core: 11 models transforming raw entities into a conformed star schema (fact_taps, dim_*).
  • Quality Gate: 80 automated unit & schema tests blocking corrupted data from reporting views.

3. Orchestration & BI

  • Apache Airflow: Automated DAGs for weekly GTFS ingestion and nightly warehouse builds.
  • Apache Superset: Read-only visual analytics with superset_ro security roles.
  • Guest Token Gateway: FastAPI service issuing ephemeral guest tokens for public dashboard embeds.
